# Phase 09 - Feed Formulation and Feed Mill

## Objective
Implement feed manufacturing as a production system.

## Tasks
- Feed types.
- Formulations.
- Formula ingredients.
- Nutritional data fields.
- Cost per kg/bag/tonne.
- Production orders.
- Planned raw materials.
- Actual consumption.
- Finished feed batches.
- Production costing.
- Inventory integration.

## Acceptance Criteria
- [x] Nutritionist can configure formulas.
- [x] Production order calculates expected material requirements.
- [x] Completion consumes raw materials.
- [x] Completion creates finished-feed stock.
- [x] Production cost is calculated.
