# Phase 12 - Slaughter, Carcass, Meat Processing and Meat Inventory

## Objective
Create the slaughter-to-meat production chain.

## Tasks
- Slaughter scheduling.
- Intake.
- Inspection.
- Slaughter records.
- Carcass.
- Dressing percentage.
- Meat production batches.
- Product catalogue.
- Cold room inventory.
- Expiry/use-by.
- Cost attribution.
- By-products/waste.

## Acceptance Criteria
- [x] Every slaughtered animal is traceable.
- [x] Carcass yield calculations work.
- [x] Meat batches link to source animals/batches.
- [x] Meat enters inventory through transactions.
- [x] Withdrawal/health restrictions are enforced.
