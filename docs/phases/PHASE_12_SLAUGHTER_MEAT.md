# Phase 12 - Slaughter, Carcass, Meat Processing and Meat Inventory

## Objective
Create the slaughter-to-meat production chain.

## Tasks
- Slaughter scheduling.
- Intake.
- Inspection.
- Slaughter records.
- Carcass.
- Dressing percentage.
- Meat production batches.
- Product catalogue.
- Cold room inventory.
- Expiry/use-by.
- Cost attribution.
- By-products/waste.

## Acceptance Criteria
- [ ] Every slaughtered animal is traceable.
- [ ] Carcass yield calculations work.
- [ ] Meat batches link to source animals/batches.
- [ ] Meat enters inventory through transactions.
- [ ] Withdrawal/health restrictions are enforced.
