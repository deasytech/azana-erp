# Phase 08 - Inventory Transaction Engine and Procurement

## Objective
Build the auditable inventory ledger and purchasing workflow.

## Tasks
- Inventory items.
- Locations.
- Batches.
- Stock ledger.
- FIFO/configurable valuation.
- Stock counts.
- Variance.
- Approval.
- Suppliers.
- Purchase requests.
- Purchase orders.
- Goods receipts.
- Supplier invoices.
- Supplier payments.
- Reorder levels.
- Expiry alerts.

## Acceptance Criteria
- [ ] Every stock change creates a ledger transaction.
- [ ] Stock count variance requires authorized approval.
- [ ] Batch information is retained.
- [ ] FIFO/configured valuation works.
- [ ] Purchase workflow is traceable from request to payment.
