# Phase 04 - Animal Registry and Lifecycle

## Objective
Implement the digital pig passport and core animal lifecycle.

## Tasks
- Animal registration.
- Multiple identifiers.
- Animal photos.
- Parentage.
- Genetic line.
- Source/purchase details.
- Location and pen.
- Status.
- Animal movement.
- Weight records.
- Current animal state.
- Animal history.

## Acceptance Criteria
- [x] Every breeding animal has a unique permanent identifier.
- [x] Multiple identifiers can point to one animal.
- [x] Every movement is preserved.
- [x] Animal profile shows lifecycle history.
- [x] QR/barcode lookup foundation works.
