# Phase 04 - Animal Registry and Lifecycle

## Objective
Implement the digital pig passport and core animal lifecycle.

## Tasks
- Animal registration.
- Multiple identifiers.
- Animal photos.
- Parentage.
- Genetic line.
- Source/purchase details.
- Location and pen.
- Status.
- Animal movement.
- Weight records.
- Current animal state.
- Animal history.

## Acceptance Criteria
- [ ] Every breeding animal has a unique permanent identifier.
- [ ] Multiple identifiers can point to one animal.
- [ ] Every movement is preserved.
- [ ] Animal profile shows lifecycle history.
- [ ] QR/barcode lookup foundation works.
