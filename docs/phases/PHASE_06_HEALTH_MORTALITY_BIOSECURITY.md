# Phase 06 - Health, Veterinary, Mortality, Culling and Biosecurity

## Objective
Implement animal health and farm biosecurity.

## Tasks
- Health events.
- Vaccination schedules.
- Treatments.
- Medicine batches.
- Withdrawal periods.
- Veterinary visits.
- Lab results.
- Mortality.
- Culling.
- Quarantine/isolation.
- Visitor management.
- Biosecurity checks.
- Health alerts.

## Acceptance Criteria
- [x] Active withdrawal animals cannot be sold/slaughtered.
- [x] Mortality records support required dimensions.
- [x] Vaccination reminders work.
- [x] Culling records preserve financial/operational information.
- [x] Visitor access records are retained.
