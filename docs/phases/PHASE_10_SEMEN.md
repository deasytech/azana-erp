# Phase 10 - Semen Production, Laboratory QC and Inventory

## Objective
Implement semen as a first-class commercial product.

## Tasks
- Boar management.
- Collection.
- Laboratory evaluation.
- Semen batch numbering.
- QC.
- Release/quarantine/expiry/destruction.
- Semen inventory.
- Breed/boar/batch traceability.
- Production targets.
- Price lists.

## Acceptance Criteria
- [x] Every collection creates a traceable batch.
- [x] QC status controls saleability.
- [x] Failed batches cannot be sold.
- [x] Inventory distinguishes breed, boar, batch and expiry.
- [x] Planning targets are configurable.
