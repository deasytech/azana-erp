# Phase 10 - Semen Production, Laboratory QC and Inventory

## Objective
Implement semen as a first-class commercial product.

## Tasks
- Boar management.
- Collection.
- Laboratory evaluation.
- Semen batch numbering.
- QC.
- Release/quarantine/expiry/destruction.
- Semen inventory.
- Breed/boar/batch traceability.
- Production targets.
- Price lists.

## Acceptance Criteria
- [ ] Every collection creates a traceable batch.
- [ ] QC status controls saleability.
- [ ] Failed batches cannot be sold.
- [ ] Inventory distinguishes breed, boar, batch and expiry.
- [ ] Planning targets are configurable.
