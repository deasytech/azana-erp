# Phase 07 - Grower/Finisher Management and Feed Consumption

## Objective
Track production performance of growing animals.

## Tasks
- Grower/finisher batches.
- Weight progression.
- Feed consumption.
- Mortality integration.
- ADG.
- FCR.
- Cost per pig.
- Cost per kg.
- Expected market date/weight.
- Production KPI calculations.

## Acceptance Criteria
- [ ] ADG is calculated from valid weight records.
- [ ] FCR uses defined feed and weight gain periods.
- [ ] Mortality affects active batch counts.
- [ ] Production costs can be attributed to animals/batches.
